A local inference workflow uses a larger target language model and a smaller draft model. The draft model proposes several future tokens, while the target model checks those proposals. Increasing the draft depth can reduce the number of target-model decoding steps when acceptance is high, but it also increases draft-model work and can waste computation when proposals are rejected. Model loading, prompt processing, memory pressure, quantization, prompt length, and output length all affect the observed wall-clock result. Explain why a benchmark should keep a non-speculative target-only baseline beside every speculative configuration.
